## 写法

```markdown
# <标题>

- 日期：YYYY-MM-DD
- 影响：<用户看到什么 / 数据错在哪>
- 发现方式：<探针 / 测试 / 真实事故>

## 当时怎么想的
## 错在哪
## 改成了什么
## 防复发（测试 / 守卫 / 文档）
```

## 判据

一条教训如果没有落到测试、守卫或文档，就还没吸收——下次还会犯。
